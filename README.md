# MATLAB | Ideal Reactor Comparison

## Project Overview
This project uses MATLAB to model and compare the performance of three ideal chemical reactor configurations:
- Batch Reactor
- Continuous Stirred Tank Reactor (CSTR)
- Plug Flow Reactor (PFR)
The model applies first-order reaction kinetics to hydrogen peroxide decomposition, examining how reactor configuration influences reactant conversion and the time required to achieve a target conversion.
## Project Objectives
- Apply chemical reaction engineering principles to mathematical modelling.
- Implement analytical reactor design equations in MATLAB.
- Compare conversion profiles for batch, CSTR and PFR reactors.
- Evaluate reactor performance at a target conversion of 80%.
- Visualise and interpret the results.
## Software and Skills
**Software:** MATLAB
**Engineering skills:** Reaction kinetics, reactor design equations, mathematical modelling, data visualisation and performance analysis.
## Running the Model
1. Download the MATLAB `.m` script from this repository.
2. Open the file in MATLAB.
3. Select **Run**.
4. Review the generated figures and numerical results in the Command Window.
The model assumes ideal reactor behaviour, constant temperature and first-order kinetics. The kinetic parameter should be treated as a model input unless supported by a verified literature reference.
